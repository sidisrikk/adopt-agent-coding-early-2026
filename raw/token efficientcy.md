# Context Management & Interaction Styles

- Caveman Interaction: การสั่งแบบสั้น ชัดเจน ไม่เยิ่นเย้อ
- Compact Command
- Sidenotes: วิธีจัดการ Task ยาวๆ โดยไม่ให้ Context บวม
- Todo Tool: ใช้ Agent ช่วย List และ Track งานตัวเอง

# Token Optimization: ใช้ของแพงให้คุ้ม (Topic 10)

- การเลือกใช้ "Right Model for the Right Job" (เช่น โมเดลเล็กตรวจ Typo, โมเดลใหญ่แก้ Logic)
- Cutover Context: เมื่อจบ Story หนึ่ง ให้ล้าง Context เพื่อเริ่มใหม่ ลด Noise และประหยัด Token
