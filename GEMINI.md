# Project Overview: Adopting Agentic Coding Presentation

## Directory Overview
This directory contains the materials, drafts, and resources for a 30-minute presentation titled **"Adopting Agentic Coding."** The presentation is aimed at mid-level developers and focuses on the theory and practice of moving beyond simple autocomplete (Level 1/2) to collaborative, autonomous AI workflows (Level 3/4). The project is a non-code repository, primarily consisting of documentation, raw notes, a custom HTML presentation, and a collection of reference links.

## Key Files and Directories

- **`presentation.html`**: The main presentation slide deck built with HTML, CSS, and some JavaScript (Mermaid for diagrams). It follows an assertion-evidence visual structure.
- **`docs/agentic-coding-presentation-design.md`**: The structured outline and design document for the presentation. It details the audience, duration, and slide-by-slide topics (ranging from Context Windows and Token Efficiency to Orchestration and Subagents).
- **`resources.md`**: A comprehensive collection of links and references related to AI coding fundamentals, memory techniques, token compression, and various skill marketplaces.
- **`raw/`**: A directory containing raw markdown notes and drafts (e.g., `context window.md`, `orchestration.md`, `team collaboration.md`) that serve as the foundation for the presentation's content.
- **`raw/images/`**: Contains the image assets (e.g., `contextwindow.png`, `middleloss.png`) referenced in the `presentation.html` slides.
- **`.agents/` & `skills-lock.json`**: Configuration and definitions for custom agent skills, specifically including a `presentation-design` skill used in the context of this project.

## Usage

- **Viewing the Presentation:** To view the slides, simply open `presentation.html` in any modern web browser.
- **Reviewing the Script/Outline:** Read `docs/agentic-coding-presentation-design.md` to understand the flow, talking points, and pacing of the 30-minute talk.
- **Exploring Concepts:** The `raw/` directory provides deeper dives into individual topics like "Lost in the Middle" context issues, asynchronous workflows (HITL, AFK), and agent orchestration.
- **Further Reading:** Refer to `resources.md` for external tools, learning hubs, and community marketplaces for agent skills.
